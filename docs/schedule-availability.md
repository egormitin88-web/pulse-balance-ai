# Новая функция: только занятия со свободными местами

Ветка: `feature/schedule-availability`. Пункт 2 ДЗ PRO.

## Поведение и приёмка

На странице «Расписание» появился переключатель «Только свободные места» и счётчик найденных занятий.

- По умолчанию переключатель выключен и заполненные занятия остаются видны.
- После включения остаются только занятия с `free_places > 0`.
- Переключатель работает одновременно с фильтром направления.
- Отключение возвращает заполненные занятия выбранного направления.
- Если подходящих занятий нет, отображается объяснение и способ сбросить фильтр.
- Фильтрация не меняет порядок занятий, данные в БД, авторизацию и правила записи.

## Автоматическая проверка

Из корня проекта, Node.js 22.12+ (проверено на 24.20):

```powershell
npm.cmd test
npm.cmd run build
```

Результат: пять тестов прошли; TypeScript и Vite успешно собрали интерфейс.

Тесты находятся в `frontend/tests/schedule.test.mjs`, проверяемая функция — в `frontend/src/schedule.ts`. Проверяются выключенный фильтр, исключение заполненных занятий, сочетание с направлением, возврат списка и отсутствие результатов. Тестовые массивы заморожены, поэтому изменение исходных данных приводит к ошибке.

## Ручная проверка в браузере

Проведена 10 ноября 2026 года на `http://127.0.0.1:8002`, без входа в аккаунт. Для неё подготовлена отдельная SQLite в игнорируемой папке `data/feature-preview`. Одно занятие йогой и все занятия боксом отмечены заполненными только в этой тестовой БД.

| Шаг | Ожидание | Факт |
|---|---|---|
| Открыть «Расписание», выбрать «Йога» | Видны свободные и заполненные занятия | 7 занятий, одно с 0 мест |
| Включить «Только свободные места» | Заполненное занятие скрыто | Осталось 6 занятий |
| Выключить переключатель | Заполненное занятие вернулось | Снова 7 занятий |
| Выбрать «Бокс» и включить переключатель | Пустой список и понятное объяснение | Счётчик 0, показана подсказка |
| С включённым переключателем выбрать «Йога» | Фильтры работают совместно | 6 занятий со свободными местами |

Основная PostgreSQL при подготовке этих заполненных занятий не менялась.

## Проверочная публикация ветки

Для окружения Vercel Preview подготовлена отдельная ветка Neon `preview-schedule-availability`, созданная как копия учебной `production`. Переменные Preview указывают на эту копию; локальная `.env.local` и переменные Production не менялись. Ветка БД автоматически истекает через 7 дней после создания (17 ноября 2026 года).
